# Companion XL – Magyar receptapp

Ez a repository a mobilra optimalizált PWA első próba-verziója.

Jelenlegi tartalom:
- 8 magyarított Companion XL recept
- keresés receptnévre és hozzávalóra
- kategóriaszűrés
- kedvencek helyi mentéssel
- „Mit főzzek ma?” funkció
- lépésenkénti főzési mód
- Companion-beállítások kiemelve
- mobilbarát PWA felület

Következő fejlesztési lépés: a teljes receptkönyv 300 receptjének strukturált adatbázisba rendezése és az eredeti receptfotók beépítése.

A GitHub Pages bekapcsolása után az alkalmazás a repository Pages címén lesz elérhető.
